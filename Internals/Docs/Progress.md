## Commands
- **SPC + cd** -> Change directory working
- **SPC + mk** -> Create directory at path if path !exist
- **SPC + h**  -> Toggle hidden directories
- **SPC + cp** -> Copy - path or browse mode
- **SPC + mv** -> Move- path or browse mode
- **SPC + rn** -> Cheaty rename 
- **SPC + rm** -> Remove + confirm
