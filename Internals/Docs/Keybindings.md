# Keybindings

## Navigation
`h` - back dir 
`l` - forward dir
`k` - up
`j` - down

Leader (SPC):
`cd` - jump to arbitrary path (type it)
`h` - toggle hidden files (dotfiles)
`mk` - create file/dir (prompts which)
`mv` - move selected (type path, or tab then browse + enter)
`cp` - copy selected (type path, or tab then browse + enter)
`rn` - rename selected
`rm` - delete selected (with confirm)
